# API Structure - Definición de Endpoints y Tipos

## 📝 Tipos de Datos (DTOs)

### Base Response Type
```typescript
// api/types.ts

// Respuesta genérica del servidor
export interface ApiResponse<T> {
  success: boolean;
  data: T;
  message?: string;
  timestamp?: string;
  statusCode: number;
}

// Respuesta paginada
export interface PaginatedResponse<T> {
  items: T[];
  total: number;
  page: number;
  pageSize: number;
  totalPages: number;
}

// Error de la API
export interface ApiError {
  code: string;
  message: string;
  details?: Record<string, string>;
  statusCode: number;
}
```

### Domain Models (Usuario)
```typescript
// Modelos del dominio
export interface User {
  id: string;

  role: 'admin' | 'user' | 'guest';

```

## 🌐 API Endpoints Mapeados

### Usuarios

| Método | Endpoint | Descripción | Response |
|--------|----------|-------------|----------|
| **GET** | `/api/users` | Listar todos los usuarios | `PaginatedResponse<User[]>` |
| **GET** | `/api/users/{id}` | Obtener usuario por ID | `ApiResponse<User>` |
| **POST** | `/api/users` | Crear nuevo usuario | `ApiResponse<User>` |
| **PUT** | `/api/users/{id}` | Actualizar usuario | `ApiResponse<User>` |
| **DELETE** | `/api/users/{id}` | Eliminar usuario | `ApiResponse<{ success: boolean }>` |

**Headers requeridos:**
```
Authorization: Bearer <token>
Content-Type: application/json
```

### Productos

| Método | Endpoint | Descripción | Response |
|--------|----------|-------------|----------|
| **GET** | `/api/products` | Listar productos | `PaginatedResponse<Product[]>` |
| **GET** | `/api/products/{id}` | Obtener producto | `ApiResponse<Product>` |
| **POST** | `/api/products` | Crear producto (admin) | `ApiResponse<Product>` |
| **PUT** | `/api/products/{id}` | Actualizar producto (admin) | `ApiResponse<Product>` |
| **DELETE** | `/api/products/{id}` | Eliminar producto (admin) | `ApiResponse<void>` |

**Query Parameters:**
```
GET /api/products?page=1&pageSize=20&search=laptop&category=electronics&sortBy=price
```

### Pedidos

| Método | Endpoint | Descripción | Response |
|--------|----------|-------------|----------|
| **GET** | `/api/orders` | Listar pedidos (del usuario) | `PaginatedResponse<Order[]>` |
| **GET** | `/api/orders/{id}` | Obtener pedido | `ApiResponse<Order>` |
| **POST** | `/api/orders` | Crear pedido | `ApiResponse<Order>` |
| **PUT** | `/api/orders/{id}` | Actualizar estado (admin) | `ApiResponse<Order>` |

## 🔐 Autenticación

### Login
```
POST /api/auth/login
Body: { email: string, password: string }
Response: { token: string, user: User }
```

### Logout
```
POST /api/auth/logout
Headers: Authorization: Bearer <token>
```

### Refresh Token
```
POST /api/auth/refresh
Body: { refreshToken: string }
Response: { token: string }
```

## 🔄 Estados de Respuesta HTTP

| Código | Significado | Caso de Uso |
|--------|------------|-----------|
| **200** | OK | Request exitoso |
| **201** | Created | Recurso creado |
| **204** | No Content | Eliminación exitosa |
| **400** | Bad Request | Datos inválidos en request |
| **401** | Unauthorized | Falta token o token inválido |
| **403** | Forbidden | Usuario no tiene permisos |
| **404** | Not Found | Recurso no existe |
| **409** | Conflict | Duplicado o conflicto |
| **500** | Server Error | Error en el servidor |
| **503** | Service Unavailable | Servidor no disponible |
