## 🏗️ Arquitectura General

```
┌─────────────────────────────────────────────────────────────┐
│                     UI / User Interface                      │
│  (Pages, Components, Forms, Displays)                        │
└──────────────────────┬──────────────────────────────────────┘
                       │
                       ↓
┌─────────────────────────────────────────────────────────────┐
│              Service Layer (Business Logic)                  │
│  (userService, productService, ordersService, etc.)          │
└──────────────────────┬──────────────────────────────────────┘
                       │
                       ↓
┌─────────────────────────────────────────────────────────────┐
│              API Client (HTTP / Communication)               │
│  (apiClient, axios instance, fetch wrapper)                  │
└──────────────────────┬──────────────────────────────────────┘
                       │
                       ↓
┌─────────────────────────────────────────────────────────────┐
│                  Backend API Endpoints                       │
│  (REST, GraphQL, WebSocket servers)                          │
└─────────────────────────────────────────────────────────────┘
```

---

## 🔑 Principios Clave

| Principio | Descripción |
|-----------|------------|
| **Separación de Capas** | UI → Servicios → Cliente API → Backend |
| **Single Responsibility** | Cada capa tiene una responsabilidad clara |
| **Reutilización** | Servicios centralizados, usados en múltiples componentes |
| **Testing** | Cada capa es testeable de forma independiente |
| **Type Safety** | Tipos bien definidos en todas las capas |
| **Error Handling** | Manejo consistente de errores |
| **Caching** | Evitar llamadas innecesarias |

## 🔄 Flujo de Datos

### Flujo Típico: Obtener Datos

1. **Usuario interactúa** → Click en botón "Cargar productos"
2. **Componente** → Llama a hook `useProducts()`
3. **Hook** → Llama a `productService.getAll()`
4. **Servicio** → Transforma datos si es necesario, luego llama `apiClient.get()`
5. **API Client** → Hace la request HTTP
6. **Backend** → Retorna datos
7. **Cadena inversa** → Los datos llegan de vuelta al componente
8. **UI Actualiza** → Pantalla muestra los productos

```
Component
    ↓
Hook (useProducts)
    ↓
Service (productService)
    ↓
API Client (apiClient.get)
    ↓
Backend API
    ↓ (Response)
Transform Data
    ↓
Update Component State
    ↓
Render UI
```
