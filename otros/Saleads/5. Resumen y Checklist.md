# Draft en Saleads - Resumen Ejecutivo y Checklist

## 📌 ¿QUÉ ES UN DRAFT?

Un **Draft en Saleads** es un **lead incompleto o sin validar** que:
- ✏️ Está siendo creado o editado
- 🔴 Tiene información faltante o provisional
- ⏸️ No está en el pipeline de ventas activo
- 🔄 Puede ser completado, confirmado o descartado
- 📊 No aparece en reportes hasta ser confirmado

**Estado:** 🟡 DRAFT

---

## 🎯 Casos de Uso Principales

| Caso | Descripción | Acción |
|------|------------|--------|
| **Import Incompleto** | Importar contactos sin validar | Completar datos antes de activar |
| **Creación Manual** | Usuario crea lead con información parcial | Rellenar campos antes de asignar |
| **Lead Duplicado** | Se detecta posible duplicado | Revisar y fusionar si es necesario |
| **Validación** | Lead espera validación de datos | Confirmar datos y activar |
| **Asignación Pendiente** | Lead sin vendedor asignado | Asignar y confirmar |

---

## 📊 Estados del Lead

```
DRAFT (🟡) → ACTIVO (🟢) → CALIFICADO (🔵) → OPORTUNIDAD → GANADO ✅
  ↓
  └───────────────────────── PERDIDO (❌)──────────────────────┘
```

**Solo DRAFT y ACTIVO son administrados en esta sección.**

## 🔧 API Endpoints Principales

| Método | Endpoint | Uso |
|--------|----------|-----|
| **POST** | `/api/drafts` | Crear nuevo draft |
| **GET** | `/api/drafts` | Listar todos los drafts |
| **GET** | `/api/drafts/{id}` | Obtener draft específico |
| **PUT** | `/api/drafts/{id}` | Editar draft |
| **DELETE** | `/api/drafts/{id}` | Descartar draft |
| **POST** | `/api/drafts/{id}/confirm` | Confirmar y activar |
| **POST** | `/api/drafts/{id}/validate` | Validar datos |

## 🔄 Flujo Principal

### 1. Crear Draft
```
Usuario completa mínimo (nombre, email, empresa)
                 ↓
         API POST /drafts
                 ↓
Servidor valida y crea documento
                 ↓
Sistema retorna Draft en estado 🟡
                 ↓
UI muestra formulario incompleto
```

### 2. Completar/Editar Draft
```
Usuario llena información faltante
                 ↓
Real-time validation on each field
                 ↓
API PUT /drafts/{id}
                 ↓
Servidor actualiza y calcula completitud
                 ↓
UI muestra progreso (60% → 80% → 100%)
```

### 3. Confirmar Draft
```
Completitud = 100% ✅
                 ↓
Usuario click "Confirmar y Activar"
                 ↓
API POST /drafts/{id}/confirm
                 ↓
Servidor:
  - Valida todos los datos
  - Detecta duplicados
  - Cambia estado draft → activo
  - Asigna a vendedor
  - Registra fuente
                 ↓
Lead ahora 🟢 ACTIVO
                 ↓
Aparece en pipeline de ventas
```

## ✅ Validaciones Automáticas

### En Formulario (Cliente)
```
Nombre: ✓ No vacío
Email: ✓ Formato válido + NO duplicado
Teléfono: ✓ Formato de país correcto
Empresa: ✓ No vacío
```

### En Servidor
```
- Verificar token JWT válido
- Validar formato de todos los campos
- Buscar duplicados en BD
- Calcular completitud
- Verificar permisos del usuario
- Detectar conflictos
```

## ⚠️ Errores Comunes

| Error | Causa | Solución |
|-------|-------|----------|
| **Email duplicado** | Lead ya existe | Fusionar con existente |
| **Teléfono inválido** | Formato incorrecto | Usar formato internacional |
| **Falta información** | Campos obligatorios sin llenar | Completar todos los campos |
| **No se puede confirmar** | Completitud < 100% | Rellenar todos los campos |
| **Acceso denegado** | No eres propietario | Contactar al propietario |

## 🎯 Conclusión

El sistema de **Drafts en Saleads** es un mecanismo de **control de calidad** que:

✅ Asegura que solo leads con información completa entren al pipeline
✅ Previene duplicados y datos basura
✅ Permite revisión antes de confirmar
✅ Mantiene auditoría de cambios
✅ Facilita importación sin validación inmediata

**Es un paso crítico en el flujo de creación de leads.**
