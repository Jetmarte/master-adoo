# 📄 DRAFT EN SALEADS - One Page Summary

## 🎯 En Una Página

### ¿QUÉ ES UN DRAFT?

```
🟡 DRAFT = Lead Incompleto + Sin Validar + No en Pipeline + Requiere 100% para Activar
```

---

## 🔄 LIFECYCLE

```
CREAR → EDITAR → VALIDAR → CONFIRMAR → ACTIVO
🟡      (60%)    ✅         (100%)      🟢
```

---

## 📋 CAMPOS REQUERIDOS vs OPCIONALES

| Requerido ✓ | Opcional - |
|---|---|
| Nombre | Teléfono |
| Email | Cargo |
| Empresa | Industria |
| | País |
| | Presupuesto |
| | Timeline |

**Completitud = (campos requeridos completados / total) × 100**

---

## 🌐 API ENDPOINTS (Principales)

```
POST   /api/drafts              → Crear nuevo draft
GET    /api/drafts              → Listar drafts
PUT    /api/drafts/{id}         → Editar draft
POST   /api/drafts/{id}/confirm → Confirmar y activar
DELETE /api/drafts/{id}         → Descartar
```

## 🎬 FLUJO RÁPIDO (User POV)

```

   ↓
2. Click "Editar" en draft
   ↓
3. Rellenar campos faltantes
   ↓
4. Guardar (PUT /api/drafts/{id})
   ↓
5. Completitud sube a 100%
   ↓
6. Click "Confirmar y Activar"
   ↓
7. Seleccionar vendedor y fuente
   ↓
8. Confirmar (POST /api/drafts/{id}/confirm)
   ↓
9. ✅ Lead ACTIVO en pipeline
```

## 🚨 ERRORES COMUNES

```
❌ 400: Email duplicado          → Buscar existente
❌ 400: Teléfono inválido        → Usar formato +XX
❌ 400: Campos obligatorios      → Rellenar todos
❌ 401: No autenticado           → Iniciar sesión
❌ 403: No tiene permisos        → Contactar admin
❌ 409: Conflicto/duplicado      → Verificar datos
```

## 🎓 CASOS DE USO

```
1️⃣ IMPORTACIÓN INCOMPLETA
   → Importar contactos
   → Validar en BD como DRAFT
   → Usuario completa datos
   → Confirma cuando 100%

2️⃣ CREACIÓN MANUAL
   → Usuario crea lead manualmente
   → Datos parciales iniciales
   → Rellenar campos faltantes
   → Activar cuando completo

3️⃣ DETECCIÓN DE DUPLICADOS
   → Sistema detecta posible duplicado
   → Lead en DRAFT para revisión
   → Usuario verifica y fusiona si necesario

4️⃣ VALIDACIÓN DE DATOS
   → Lead espera validación
   → Sistema marca problemas
   → Usuario corrige
   → Confirma cuando todo válido
```
