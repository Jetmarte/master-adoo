```
┌──────────────────┐
│  USER INTERACTION│
└────────┬─────────┘
         │
         ↓
┌─────────────────────────────────────┐
│ 1. Abre sección de Drafts           │
│    GET /api/drafts                  │
└────────┬────────────────────────────┘
         │
         ↓
┌─────────────────────────────────────┐
│ 2. Click en "Editar"                │
│    GET /api/drafts/D1               │
│    Renderiza <DraftLeadForm />      │
└────────┬────────────────────────────┘
         │
         ↓
┌─────────────────────────────────────┐
│ 3. Completa formulario              │
│    Validación en tiempo real        │
│    Calcula completitud              │
└────────┬────────────────────────────┘
         │
         ↓
┌─────────────────────────────────────┐
│ 4. Click "Guardar Draft"            │
│    PUT /api/drafts/D1               │
│    Guarda cambios                   │
└────────┬────────────────────────────┘
         │
         ↓
┌─────────────────────────────────────┐
│ 5. Click "Confirmar y Activar"      │
│    POST /api/drafts/D1/confirm      │
│    Cambia estado draft → activo     │
└────────┬────────────────────────────┘
         │
         ↓
┌─────────────────────────────────────┐
│ RESULT: Lead ACTIVO en Pipeline     │
│         Asignado a Vendedor         │
│         Listo para Seguimiento      │
└─────────────────────────────────────┘
```
