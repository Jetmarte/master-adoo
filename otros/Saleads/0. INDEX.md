## 🔑 Key Concepts Quick Ref

### What is a Draft?
See: [[1. Draft en Saleads|Definition]]

**Quick Answer:** A draft is an incomplete lead that requires 100% completion before being activated into the sales pipeline.

### Draft Lifecycle
See: [[6. Diagrama Visual - Flujo Interactivo|Diagrams]] - Estado de Transición Detallado

```
DRAFT (🟡) → ACTIVO (🟢) → CALIFICADO (🔵) → OPORTUNIDAD → GANADO (✅)
  ↓
  └─────────────────────────────────────→ PERDIDO (❌)
```

### Draft States
See: [[1. Draft en Saleads|Definition]] - Estados del Lead

| Estado | Color | Meaning |
|--------|-------|---------|
| **DRAFT** | 🟡 | Incomplete, not in pipeline |
| **ACTIVE** | 🟢 | Complete, in pipeline |
| **QUALIFIED** | 🔵 | Meets criteria |
| **OPPORTUNITY** | 🟠 | Sales opportunity |
| **WON** | ✅ | Closed won |
| **LOST** | ❌ | Closed lost |

### Required Fields
See: [[2. Draft API y Componentes|API & Components]] - DTOs

```
✓ nombre (required)
✓ email (required)
✓ empresa (required)
- telefono (optional)
- cargo (optional)
- industria (optional)
- ... more optional fields
```

### API Endpoints
See: [[2. Draft API y Componentes|API & Components]] - Endpoints

```
POST   /api/drafts                  Create
GET    /api/drafts                  List
GET    /api/drafts/{id}             Get one
PUT    /api/drafts/{id}             Update
DELETE /api/drafts/{id}             Delete
POST   /api/drafts/{id}/confirm     Confirm & activate
POST   /api/drafts/{id}/validate    Validate
```

### Completeness (%)
See: [[1. Draft en Saleads|Definition]] - Completitud

- **0-50%:** Very incomplete
- **51-80%:** Mostly complete
- **81-99%:** Almost complete
- **100%:** Ready to confirm ✅

### Validations
See: [[2. Draft API y Componentes|API & Components]] - Validations

```
✓ Email format valid
✓ Email not duplicate
✓ Phone format valid
✓ Required fields not empty
✓ All data types correct
```
