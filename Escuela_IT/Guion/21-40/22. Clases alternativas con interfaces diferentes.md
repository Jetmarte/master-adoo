# v220. Clases Alternativas con Interfaces Diferentes

## Errores

- **5.2.7. Principio “No te repitas” (DRY)**
  - Las clases `PutController` y `MoveController` tienen código repetido en los métodos `put` y `move`.
- **5.5.4. Código Sucio por Clases Alternativas con Interfaces Diferentes**
  - Las clases `PutController` y `MoveController` tienen métodos `put` y `move` diferentes cuando realizan semánticamente la misma función de control.

## Solución

- **4.4.7. Herencia**
- **5.5.6. Patrón Método Plantilla**
  - Se homogenizan ambos métodos y se conforma una jerarquía de herencia de ambas clases heredando de `ColocateController`.
