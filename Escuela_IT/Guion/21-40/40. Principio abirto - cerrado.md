# v400. Principio Abierto/Cerrado

## Solución

- **Flexible:**
  - Se puede ampliar la funcionalidad añadiendo más controladores y algún modelo o método en los existentes.
  - Se puede ampliar a nuevas configuraciones distribuidas, añadiendo más controladores proxy que conecten a los actuales.
  - Se pueden ampliar las tecnologías de vista (móviles, web, escritorio, ...), añadiendo nuevas vistas.
- **Robusto:**
  - Se pueden probar con pruebas automáticas todas las clases menos las vistas que interactúan con el usuario (y se podría conseguir con mocks).
- **Legible:**
  - Cada clase es experta en la información con alta cohesión y bajo acoplamiento.
- **Reusable:**
  - Las clases de utilidad y todos los modelos en otro software para el juego de las tres en raya (para demos de inteligencia artificial, ...).
