# v040. Descomposición Funcional

- Se están usando nombres de acciones para nombrar clases.
- La descomposición funcional significa orientado a funciones, en que las clases están orientadas a acciones.
- Un síntoma es usar `static` por todo lado.
- Si tienes estructuras de datos compartidas por varias acciones, pero luego ves que esa estructura no es la correcta y debes cambiarla.
- Pero esto conlleva cambiar por todas partes y afecta a muchas clases; es un ejemplo de descomposición funcional.
