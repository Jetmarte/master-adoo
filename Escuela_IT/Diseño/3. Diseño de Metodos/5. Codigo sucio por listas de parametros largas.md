Sinónimos:

 Lista de Parámetros Larga (Long Parameter List) [Smell Code

(Refactoring); Martin Fowler]

 Demasiados Argumentos (Too Many Arguments) [Smell Code (Clean

Code) - Robert Martin]

 Justificación:

▫ Son difíciles de entender

▫ Son difíciles de probar todas la combinaciones de argumentos

 Solución:

▫ Eliminar el parámetro cuando puedes obtenerlo a partir de algún objeto

que ya conoces

▫ Eliminar varios parámetros suministrando un objeto que los facilite

▫ Crear un objeto que agrupe varios parámetros y asigna responsabilidad a

sus clase

 Métrica:

 Funciones deberán tener un número pequeño de argumentos. Sin

argumentos es lo mejor, seguido por uno, dos. Tres debería evitarse y

más de tres es muy cuestionable y debe considerarse como un prejuicio.
