Sinónimos:

 Clases Alternativas con Diferentes interfaces (Alternative Classes

with Different Interfaces) [Smell Code (Refactoring); Martin Fowler]

 Justificación:

▫ Complejidad innecesaria

 Solución:

▫ Renombra los métodos que hacen lo mismo pero tienen nombre

diferentes sin la oportuna sobrecarga.

▫ Mueve responsabilidades de las clases hasta que los métodos hacen

lo mismos y tienen el mismo nombre: homogina el código

▫ Mueve los métodos a clases padre o como poco la interfaz
