**Título:** [[1. Respetar estandares de codigo limpio]]

**Sinónimos:**
* Follow Standard Conventions [Clean Code - Robert Martin]

**Justificación:**

Es fundamental que cada equipo de desarrollo adopte y siga un **estándar de codificación unificado**. Este estándar debe basarse en las **convenciones comunes de la industria del software** y definir claramente aspectos clave como:

*   La ubicación apropiada para la declaración de variables de instancia.
*   Las directrices para nombrar clases, métodos y variables de manera consistente y descriptiva.
*   La convención sobre la colocación de llaves y otros elementos de sintaxis.

La adhesión a estas convenciones por parte de **todos los miembros del equipo** es crucial. Esto implica una madurez profesional donde se comprende que la consistencia en la aplicación de las reglas (como la colocación de llaves) es más importante que la preferencia individual, siempre y cuando exista un acuerdo grupal.

Idealmente, el código mismo debería servir como el **documento vivo de estas convenciones**. No debería ser necesario un documento separado para describir las reglas, ya que la lectura del código bien escrito y estandarizado proporcionará los ejemplos claros y prácticos de cómo se deben seguir las directrices.
