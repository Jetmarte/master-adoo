## 🔴 CATEGORIZACIÓN CLÁSICA

### Qué es
```
Propiedades necesarias Y suficientes
Booch: "Entidades con propiedades en común"
```

### Ejemplo
```
AVE = Tiene plumas AND pico AND alas AND vuela

Paloma: ✅ Sí (tiene todo)
Pingüino: ❌ No (no vuela) = NO es ave

PROBLEMA: Pingüino INTUITIVAMENTE es un ave
```

### Cuándo usarla
```
✅ Matemáticas (2+2=4)
✅ OOP (Clases)
✅ Especificaciones
❌ Categorías naturales
```

---

## 🟡 AGRUPACIÓN CONCEPTUAL

### Qué es
```
Agrupar por CONCEPTO COMPARTIDO
No necesita propiedades exactas
```

### Ejemplo
```
AVE = "Relacionado con el concepto de ave"

Paloma: ✅ SÍ (está conectada al concepto)
Pingüino: ✅ SÍ (está conectada al concepto)
Murciélago: ❌ NO (menos conectado al concepto)

VENTAJA: Maneja excepciones
PROBLEMA: Ambigua y subjetiva
```

### Cuándo usarla
```
✅ Filosofía
✅ Análisis de dominios
✅ Categorías complejas
❌ Precisión absoluta
```

## 🟢 TEORÍA DE PROTOTIPOS

### Qué es
```
Categorías basadas en PROTOTIPO (ejemplo más típico)
Membresía en GRADOS (no binaria)

Eleanor Rosch (1970s)
= El MEJOR enfoque para categorías naturales
```

### Ejemplo
```
AVE = Similaridad a Paloma (prototipo)

Jerarquía de tipicidad:
├─ Paloma ............. 100% (prototipo)
├─ Aguila .............. 95%
├─ Gallina ............ 80%
├─ Avestruz ........... 60%
├─ Pingüino ........... 40% ← PERIFÉRICO
└─ Murciélago ......... 10% ← CUESTIONABLE

VENTAJA: Realista cognitivamente
VENTAJA: Maneja excepciones
VENTAJA: Explica cómo pensamos
```

### Cuándo usarla
```
✅ Psicología
✅ Lingüística
✅ Categorías naturales
✅ Modelar cognición
✅ MEJOR EN GENERAL
```

## 🎯 EL PROBLEMA DEL PINGÜINO

```
¿Es el PINGÜINO un AVE?

CLÁSICA:
"Un ave debe: tener plumas, pico, alas Y VOLAR"
Pingüino: ✅ plumas, ✅ pico, ✅ alas, ❌ NO vuela
Respuesta: ❌ NO es ave
Conclusión: INCORRECTA intuitivamente

AGRUPACIÓN CONCEPTUAL:
"¿Está relacionado con el concepto de ave?"
Pingüino: ✅ SÍ (es claramente un animal relacionado)
Respuesta: ✅ SÍ es ave
Conclusión: CORRECTA pero ambigua

PROTOTIPOS:
"¿Cuán similar es a Paloma (prototipo)?"
Pingüino: 40% similar (menos que Aguila pero más que Murciélago)
Respuesta: ✅ SÍ es ave (periférica)
Conclusión: CORRECTA y PRECISA
```

## 📊 APLICACIÓN EN OOP

```
CLÁSICA:
interface Ave {
  vuela: true;     // Obligatorio
  tienePlumas: true;
  tienePico: true;
}

PROBLEMA: Pingüino no puede implementar (no vuela)

PROTOTIPOS:
interface CaracteristicasAve {
  vuela?: boolean;        // Opcional
  tienePlumas?: boolean;  // Opcional
  // ...
}

function prototipicidad(ave): number {
  return (vuela ? 40 : 0) + (plumas ? 20 : 0) + ...;
}

VENTAJA: Pingüino encaja mejor
```
