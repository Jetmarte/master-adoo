## 📖 Definición

> [!quote] Stepp; Michalski
> "Las clases se generan mediante la formulación de primeras descripciones conceptuales de estas clases y, a continuación, la clasificación de las entidades de acuerdo con las descripciones."

En vez de dar una **lista cerrada de atributos** (como la categorización clásica), aquí se **describe el concepto** de la clase y luego se agrupan las entidades según qué tanto encajan con esa descripción.

| Aspecto | Categorización clásica | Agrupación conceptual |
|---|---|---|
| Base | Propiedades **necesarias y suficientes** | **Descripción / concepto** compartido |
| Criterio | Lógica booleana (cumple / no cumple) | Similitud, función, contexto, asociación |
| Límites | Precisos | Difusos |
| Naturaleza | Categorías lógicas | Categorías **probabilísticas / difusas** |

> [!tip] Idea clave
> Se trabaja con **conceptos difusos** (lógica difusa), no con conceptos puramente lógicos. Un objeto puede pertenecer *más o menos* a la categoría.

---

## 🎵 Ejemplo: "canción de amor"

Podemos afirmar un concepto como **"canción de amor"**. Es un **concepto**, más que una propiedad medible: la *"canción-de-amor-idad"* de una canción no se puede medir empíricamente.

- Si decidimos que una canción **es más** una canción de amor que otra, la situamos en esa categoría.
- Por eso la agrupación conceptual representa una **agrupación probabilística de objetos**: no exige una lista de atributos, sino una descripción del concepto.

---

## 🎨 Tipos de agrupación conceptual

| Tipo | Une a los miembros por... | Ejemplo |
|------|---------------------------|---------|
| **Similitud** | Parecido entre entidades | Fruta: manzana, plátano, fresa |
| **Función** | Sirven para lo mismo | Mueble: silla, taburete, sofá |
| **Contexto** | Aparecen en la misma situación | Comida de desayuno: huevos, café, tostadas |
| **Asociación** | Están relacionados con una actividad | Herramientas de cocina: cuchillo, sartén, olla |

## 🔧 Aplicación al análisis OO

1. Formular una **descripción conceptual** de la clase (qué representa, no una lista rígida de atributos).
2. Revisar las entidades del dominio y clasificarlas según su **relación con ese concepto**.
3. Modelar con **propiedades opcionales**, interfaces o composición en lugar de forzar herencia.

```java
// Concepto "ave": descripción flexible, sin exigir volar()
interface CaracteristicasAve {
  boolean tienePlumas();   // típico, pero no obligatorio en todos los casos
  boolean tienePico();
  boolean poneHuevos();
}

class Aguila implements CaracteristicasAve { /* además vuela */ }
class Pinguino implements CaracteristicasAve { /* además nada, no vuela */ }
```

> [!tip] Diferencia práctica
> La clásica dice *"DEBE tener A **y** B **y** C"*. La conceptual dice *"se relaciona con el concepto, **puede** tener A, B, C y otras"*.

## ✅ Ventajas vs ❌ Límites

| ✅ Ventajas | ❌ Límites |
|-------------|------------|
| Tolera excepciones y miembros "menos típicos" | **Ambigüedad:** ¿qué tan relacionado debe estar para pertenecer? |
| Más flexible y realista que la clásica | **Subjetividad:** dos personas pueden agrupar distinto |
| Refleja cómo categorizamos en el lenguaje natural | Difícil tomar decisiones binarias (sí/no) |
| Permite que un objeto pertenezca a varios conceptos | Menos formalizable y verificable |

## ✅ Conclusión para examen

1. Agrupación conceptual = clasificar por **descripción / concepto**, no por lista fija de propiedades [Stepp; Michalski].
2. Maneja **conceptos difusos** y pertenencia **probabilística** (ej.: "canción de amor").
3. **Ventaja:** flexible y realista ante excepciones.
4. **Límite:** ambigua y subjetiva → difícil de formalizar y validar.

> [!question] Pregunta típica
> *"¿En qué se diferencia la agrupación conceptual de la categorización clásica?"*
> **Respuesta:** la clásica exige propiedades **necesarias y suficientes** (pertenencia binaria); la conceptual agrupa por **relación con un concepto** (pertenencia difusa/probabilística), aceptando excepciones.
