# 5. Relación de dependencia (uso)

> [!info] Relación **cliente–servidor puntual** · Sección 4.4.5
> Anterior: [[4. Relacion de asociacion|Asociación]] · Siguiente: [[6. Comparativa entre clases por colaboracion|Comparativa]]

---

## 📖 Definición

La **dependencia (uso)** es la relación que se establece **momentáneamente** entre un **cliente** y **cualquier servidor**.

> [!tip] Regla de detección
> Existe una relación de uso entre la clase **A** (cliente) y la clase **B** (servidor) si un objeto de A **disfruta de los servicios de un objeto de B** (le lanza mensajes) para cumplir su responsabilidad **en un momento dado**, sin dependencias futuras.

Palabras clave:

| Concepto | Significado |
|----------|-------------|
| **Momentánea** | El uso dura un instante o un periodo corto |
| **Cualquier servidor** | Sirve cualquier objeto de la clase servidor |
| **Sin dependencia futura** | Terminado el uso, no queda vínculo |
| **Relación más débil** | Es el acoplamiento más débil entre clases |

No se limita a cuestiones **tangibles** (ciudadano –cliente– y autobús –servidor–); también cubre relaciones **lógicas**:

| Expresión | Ejemplo (cliente – servidor puntual) |
|-----------|--------------------------------------|
| "goce" | `Espectador` – `Actor` |
| "beneficio" | `Viajante` – `Motel` |
| "cálculo" | `ServicioPrestamo` – `CalculadoraMulta` |
| "salida" | `Informe` – `Impresora` |

---

## 🧭 Características

| Característica | Valor |
|----------------|-------|
| **Visibilidad** | Pública **o** privada |
| **Temporalidad** | **Momentánea** |
| **Versatilidad** | **Alta** |

> [!note] Por qué versatilidad alta
> Al cliente le sirve **cualquier** objeto de la clase servidor: cualquier autobús, cualquier actor, cualquier impresora.

---

## 💻 Implementación en Java

La clase cliente contempla al servidor de dos formas según la visibilidad:

### Pública: parámetro o valor devuelto

```java
class ServicioPrestamo {
    // El servidor entra como parámetro: uso público
    void registrar(Prestamo prestamo, CalculadoraMulta calculadora) {
        prestamo.setMulta(calculadora.calcular(prestamo));
    }

    // O sale como valor devuelto
    CalculadoraMulta nuevaCalculadora() {
        return new CalculadoraMulta();
    }
}
```

### Privada: objeto local de un método

```java
class ServicioPrestamo {
    void imprimirComprobante(Prestamo prestamo) {
        Impresora impresora = new Impresora(); // objeto local, uso privado
        impresora.imprimir(prestamo);
    }
}
```

> [!tip] Regla práctica
> Si el servidor aparece en la **firma** del método (parámetro o retorno) → uso **público**.
> Si solo existe como **variable local** dentro del método → uso **privado**.

---

## 🆚 Dependencia vs. asociación

| Criterio | Dependencia (uso) | Asociación |
|----------|-------------------|------------|
| **Duración** | **Momentánea** | No momentánea (perdura) |
| **Servidor** | **Cualquiera** | **Determinado** |
| **Dependencia futura** | **No** | Sí |
| **En código** | Parámetro, retorno o **variable local** | Referencia como **atributo** |
| **UML** | Flecha **discontinua** | Línea continua |

---

## 📐 Notación UML

```text
ServicioPrestamo ┄┄┄┄► CalculadoraMulta     (dependencia)
Informe          ┄┄┄┄► Impresora            (dependencia)
```

- Línea **discontinua** con **flecha** desde el cliente hacia el servidor.
- Representa que el cliente **conoce** al servidor de forma puntual.

---

## ⚠️ No confundir con la "dependencia" genérica

> [!warning] Dos usos del término
> - **Dependencia (uso):** relación **puntual** entre cliente y servidor (esta nota).
> - **Dependencia en sentido amplio:** cualquier relación implica dependencia (la asociación también, y la herencia también).
>
> Cuando el enunciado dice "relación de dependencia (uso)" se refiere a la **puntual**.

---

## ✅ Conclusión para examen

1. Dependencia (uso) = colaboración **momentánea** con **cualquier** servidor y **sin dependencia futura**.
2. Visibilidad **pública o privada**, temporalidad **momentánea**, versatilidad **alta**.
3. En código: **parámetro/retorno** (pública) o **variable local** (privada).
4. Es la relación **más débil** y la de **menor acoplamiento**.
