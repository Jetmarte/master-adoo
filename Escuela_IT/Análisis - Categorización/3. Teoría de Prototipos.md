# Teoría de Prototipos

## 📌 Definición

La **Teoría de Prototipos** (Prototype Theory) propone que las categorías **no se definen por propiedades necesarias y suficientes**, sino por la **similitud con un ejemplar prototípico** (el más típico o representativo).

> **"Las categorías tienen un 'ejemplar central' que es el mejor representante de la categoría, y otros miembros se categorizan según su similitud con este prototipo."** — Eleanor Rosch

---

## 🎯 Conceptos Clave

### 1. **Prototipo (Ejemplar Central)**
```
Es el MEJOR REPRESENTANTE de una categoría.
Es el más típico, más frecuente, más característico.

EJEMPLOS:
├─ Aves: Paloma (prototipo típico)
│         Aguila (también típica)
│         Pingüino (menos típico)
│         Kiwi (periférico)
│
├─ Muebles: Silla (muy típica)
│           Mesa (típica)
│           Sofá (típico)
│           Lámpara (periférica)
│
└─ Colores: Rojo puro (prototipo de rojo)
            Rojo oscuro (menos prototípico)
            Naranja (periférico)
```

### 2. **Gradualidad de Membresía**
```
No es BINARIO (pertenece o no).
Es GRADUAL (hay grados de pertenencia).

ESCALA:
├─ 100% → Prototipo (Paloma es perfectamente un ave)
├─ 80% → Muy típico (Aguila es muy típico)
├─ 60% → Típico (Avestruz es relativamente típico)
├─ 40% → Menos típico (Pingüino es débilmente típico)
└─ 20% → Periférico (Kiwi es muy débilmente típico)
```

### 3. **Distancia Prototípica**
```
Qué tan LEJOS está un miembro del prototipo.

├─ Distancia corta → Pertenencia clara
├─ Distancia media → Pertenencia moderada
└─ Distancia larga → Pertenencia débil/cuestionable
```

```
CATEGORÍA: AVES

NIVEL 1 - PROTOTIPOS CLAROS (100%)
├─ Paloma ⭐⭐⭐⭐⭐ (prototipo más típico)
├─ Aguila ⭐⭐⭐⭐⭐ (también muy típico)
├─ Loro ⭐⭐⭐⭐⭐

NIVEL 2 - MUY TÍPICOS (80-90%)
├─ Gallina ⭐⭐⭐⭐
├─ Pato ⭐⭐⭐⭐

NIVEL 3 - TÍPICOS (60-70%)
├─ Avestruz ⭐⭐⭐
├─ Flamenco ⭐⭐⭐

NIVEL 4 - MENOS TÍPICOS (40-50%)
├─ Pingüino ⭐⭐
├─ Kiwi ⭐⭐

NIVEL 5 - PERIFÉRICOS (10-20%)
├─ ¿Murciélago? ⭐ (¿es realmente un ave?)
└─ ¿Pterodáctilo? ⭐ (¿es un ave o un dinosaurio volador?)
```

### Por Qué Esta Jerarquía

```
PALOMA (prototipo):
├─ Vuela muy bien ✅
├─ Tiene alas típicas ✅
├─ Tiene plumas bien desarrolladas ✅
├─ Tiene pico ✅
├─ Pone huevos ✅
├─ Es frecuente ✅
├─ Todos la consideran un ave ✅
└─ = PROTOTIPO IDEAL

PINGÜINO:
├─ NO vuela ❌ (diferencia importante)
├─ Tiene alas modificadas ❌ (para nadar, no volar)
├─ Tiene plumas ✅
├─ Tiene pico ✅
├─ Pone huevos ✅
├─ Es menos frecuente ❌
├─ Algunos dudan si "realmente" es un ave
└─ = PERIFÉRICO

MURCIÉLAGO:
├─ SÍ vuela ✅
├─ Pero NO tiene plumas ❌ (tiene pelaje)
├─ Tiene alas pero NO típicas ❌
├─ Tiene pico ❌ (tiene boca)
├─ NO pone huevos ❌ (da a luz crías vivas)
├─ Es menos frecuente ❌
├─ CASI NUNCA se considera un ave
└─ = CASI EXCLUIDO (pero podría estar en límite)
```

### Experimento de Eleanor Rosch

Eleanor Rosch pidió a personas que calificaran cuán "típicas" eran diferentes aves.

Moderadamente típico:
6. Pato ............................. 6.90/10

Menos típico:
9. Pingüino ......................... 3.81/10

Conclusión: No es binario (sí/no), sino gradual

## 🎨 Tipos de Prototipos

### 1. **Prototipo Estadístico**
```
El ejemplar "promedio" de la categoría.
La combinación de características más frecuentes.

EJEMPLO: Ave prototípica
├─ Tamaño: mediano (ni muy grande, ni muy pequeño)
├─ Peso: intermedio
├─ Capacidad de vuelo: buena
├─ Comportamiento: migra
└─ Alas: típicamente dimensionadas
```

### 2. **Prototipo Idealizador**
```
El ejemplar "mejor" o "más perfecto" de la categoría.
La representación mental ideal.

EJEMPLO: Ave idealizadora
├─ Vuela perfectamente
├─ Tiene todas las características "típicas"
├─ Es hermosa
├─ Es la forma en que la dibujamos
└─ Es lo que imaginamos cuando alguien dice "ave"
```

### 3. **Prototipo Socio-Cultural**
```
El ejemplar más importante o representativo
en la cultura o sociedad.

EJEMPLO: Ave socio-cultural
├─ La paloma (símbolo de paz)
├─ El águila (símbolo de fuerza)
├─ El pavo (asociado a Thanksgiving)
└─ El búho (asociado a sabiduría)
```

## 💡 Implicaciones Cognitivas

### 1. **Tiempo de Reacción**
```
Experimento: "¿Es un ave?"

Tiempo de reacción más rápido:
└─ Paloma ✅ (100ms - es prototípica)

Tiempo de reacción moderado:
└─ Pingüino ⏱️ (500ms - necesita pensar)

Tiempo de reacción más lento:
└─ Murciélago ❓ (1000ms+ - dudoso si es ave)
```

### 2. **Errores de Clasificación**
```
Las personas tienden a cometer errores
con ejemplares periféricos:

├─ Falsos positivos: "¿Murciélago? Sí, creo que es un ave"
│  (lo incluyen erróneamente)
│
└─ Falsos negativos: "¿Pingüino? No, no creo que sea un ave"
   (lo excluyen erróneamente)

Los prototipos RARA VEZ se clasifican mal.
```

### 3. **Adquisición del Lenguaje**
```
Los niños aprenden primero los PROTOTIPOS:
├─ Primero aprenden "perro" (prototipo)
├─ Luego aprenden "gato", "caballo" (similares)
└─ Después "hormigas", "serpientes" (periféricos)

No empiezan con categorías difíciles.
```

## 💻 Aplicación en OOP

### Enfoque Prototípico

```typescript
// En lugar de una interfaz rígida,
// definimos un prototipo con características típicas

interface AvePrototipo {
  nombre: string;
  // Características del prototipo (típicas)
  vuela: boolean;      // El prototipo SÍ vuela
  tienePlumas: boolean;
  tienePico: boolean;
  poneHuevos: boolean;
}

// Función para calcular "prototipicidad"
function calcularProototipicidad(ave: Ave): number {
  let puntos = 0;

  // Comparar con características del prototipo
  if (ave.vuela) puntos += 30;        // Muy importante
  if (ave.tienePlumas) puntos += 20;
  if (ave.tienePico) puntos += 20;
  if (ave.poneHuevos) puntos += 20;

  // Aumentar si es frecuente
  if (ave.esFrequente) puntos += 10;

  return Math.min(puntos, 100);
}

class Paloma {
  nombre = "Paloma";
  vuela = true;        ✅
  tienePlumas = true;  ✅
  tienePico = true;    ✅
  poneHuevos = true;   ✅
  esFrequente = true;  ✅

  prototipicidad = calcularProototipicidad(this); // 100%
}

class Pingüino {
  nombre = "Pingüino";
  vuela = false;       ❌ (diferencia importante)
  tienePlumas = true;  ✅
  tienePico = true;    ✅
  poneHuevos = true;   ✅
  esFrequente = false; ❌

  prototipicidad = calcularProototipicidad(this); // ~40%
}

class Murciélago {
  nombre = "Murciélago";
  vuela = true;        ✅
  tienePlumas = false; ❌ (tiene pelaje)
  tienePico = false;   ❌ (tiene boca)
  poneHuevos = false;  ❌ (es vivíparo)
  esFrequente = false; ❌

  prototipicidad = calcularProototipicidad(this); // ~10%
}

// Ahora podemos tomar decisiones:
if (paloma.prototipicidad > 80) {
  // Es claramente un ave
}

if (pinguino.prototipicidad > 50) {
  // Es probablemente un ave
}

if (murcielago.prototipicidad < 30) {
  // Probablemente NO es un ave
}
```

## 🎯 Ventajas de Teoría de Prototipos

### 1. **Explica Comportamiento Real**
```
✅ Por qué los humanos clasifican así
✅ Por qué hay errores sistemáticos
✅ Por qué algunos ejemplares son más típicos
```

### 2. **Maneja Excepciones Naturalmente**
```
✅ Pingüino es un ave (aunque no típicamente)
✅ Murciélago no es un ave (aunque vuela)
✅ Hay espacio para lo ambiguo
```

### 3. **Refleja Procesos Cognitivos**
```
✅ Los humanos usan prototipos para categorizar
✅ Explica tiempos de reacción
✅ Explica errores de clasificación
```

### 4. **Flexible y Realista**
```
✅ Permite gradualidad
✅ Permite categorías naturales
✅ Se adapta a la variabilidad
```

## 🎓 Conclusión

La **Teoría de Prototipos** es actualmente el enfoque más aceptado para explicar cómo las personas realmente categorizan el mundo. A diferencia de la categorización clásica:

- ✅ Permite grados de membresía
- ✅ Tiene un prototipo (ejemplar central)
- ✅ Maneja excepciones naturalmente
- ✅ Explica el comportamiento cognitivo real

El Pingüino ya no es un problema: es simplemente un ave menos típica.
