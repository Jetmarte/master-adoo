Si estás comenzando el curso:

1. Comienza por el [Índice](INDICE_CURSO_ADOO.md) - 5 min
2. Lee la [Introducción](RESUMEN_CURSO_ADOO.md#introducción) - 10 min

4. Consulta "Referencias Cruzadas" si necesitas más contexto

**Tiempo total**: 5-10 minutos

Si tienes poco tiempo:

1. Semana 1-2: Lee [Conceptos Fundamentales](RESUMEN_CURSO_ADOO.md#conceptos-fundamentales)

## Conceptos Clave del Curso

### Los 9 Patrones GRASP
```
1. Experto en Información      5. Fabricación Pura
2. Creador                     6. Indirección
3. Controlador                 7. Polimorfismo
4. Bajo Acoplamiento           8. Variaciones Protegidas
5. Alta Cohesión               9. (Este debe ser para completar)
```

### Los 5 Principios SOLID
```
S - Single Responsibility
O - Open/Closed
L - Liskov Substitution
I - Interface Segregation
D - Dependency Inversion
```

### Los 3 Principios Pragmáticos
```
YAGNI - You Aren't Gonna Need It
DRY   - Don't Repeat Yourself
KISS  - Keep It Simple Stupid
```

## Glosario Rápido

**Acoplamiento**: Medida de dependencia entre clases
**Cohesión**: Medida de relación entre responsabilidades
**GRASP**: 9 patrones para asignar responsabilidades
**SOLID**: 5 principios de diseño orientado a objetos
**Bad Smell**: Indicador de código problemático
**Refactorización**: Mejorar código sin cambiar comportamiento
**Dominio**: Mundo real del problema

## Resumen Ejecutivo (TL;DR)

**Si solo tienes 5 minutos**:

El Análisis y Diseño Orientado a Objetos (ADOO) es una metodología para crear software mantenible basada en:

1. **Análisis**: Entender el problema (clases, relaciones)
2. **GRASP**: Asignar responsabilidades (9 patrones)
3. **SOLID**: Aplicar principios (5 principios)
4. **Código Limpio**: Escribir bien
5. **Diseño**: Organizar en niveles (métodos, clases, herencia, paquetes)

**Máxima central**: "Una clase, una responsabilidad, bajo acoplamiento, alta cohesión"
